# Bhayani & Co. Chartered Accountants — Website

Static website (single `index.html`). Hosted on Render as a Static Site.

- Publish directory: `.`
- Build command: none
- Every push to `main` redeploys automatically.

## Tools (each in its own folder, live at `<site>/<folder>/`)

| Folder | Tool |
|---|---|
| `gst/` | GST Desk — GST return & reconciliation |

Data entered in a tool is saved in the user's own browser. Outlook mail and AI sorting work only inside Claude.
